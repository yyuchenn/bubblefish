CDP 主页面 JavaScript heap 观测为：打开前约 6.74 MB，导入后 344.64 MB，编辑并撤销后 345.08 MB，关闭项目后 348.08 MB。未强制 GC；这些数字不包含图片解码、Worker/WASM 或浏览器进程的整体内存，也不能据此宣称整体内存已回收。已验证的是 DOM 图片数量与全部 Blob URL 的释放。
