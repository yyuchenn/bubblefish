DeepSeek 翻译设置

配置后，在翻译服务中选择 DeepSeek 翻译。保存的设置从下一次翻译请求开始生效。

保存在当前站点或桌面应用的本地配置中，未接入系统密钥链。翻译时通过 HTTPS 发往所配置的 API 地址。

填写完整 HTTPS Chat Completions 地址，包含 /chat/completions；兼容网关需要允许浏览器跨域访问。

DeepSeek 模式显式关闭思考；OpenAI 兼容模式不发送 DeepSeek 专用的 thinking 参数。

可以从预设中选择，也可以填写兼容服务使用的模型名称。

支持 {source_lang}、{target_lang} 和 {text}。用户提示词必须包含 {text}。留空时使用默认提示词。
